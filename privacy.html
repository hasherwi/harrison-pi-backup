Privacy policy

Last updated: 13 October 2026

This policy describes how harrison-pi handles data when its owner runs the personal backup utility.

Data accessed and its purpose

The utility uses Google Drive read-only access to retrieve selected file contents and metadata such as names, folder paths, identifiers, file types, sizes, timestamps and checksums. It uses this information only to create, check and restore the owner’s backup copies.

The OAuth permission permits viewing and downloading files across the authorized account. Local configuration selects the folders used for backup. The utility does not use this permission to modify or delete the source files in Google Drive.

Storage and sharing

Backup files, inventories, verification records and operational logs are stored on devices controlled by the owner. Records and logs may contain file metadata. OAuth credentials and tokens are kept in local configuration and are not included in this public website.

The backup utility does not send Drive content to this website or its public source repository. It does not sell Drive data, use it for advertising, or use it to train AI models. Data is transferred from Google Drive to the owner’s chosen storage for the backup purpose.

Retention, deletion and revocation

The owner controls retention on their devices and can remove backup files, inventories and logs there. Revoking the app’s access in Google Account settings stops future authorized access but does not delete copies already stored on the owner’s devices. The owner can also remove the local credentials and tokens.

This public website

The site contains static app information and this policy. Its code has no sign-in, upload form, analytics script or cookie storage. It does not request Google authorization or receive Drive data.

GitHub Pages provides hosting. GitHub logs visitors’ IP addresses for security purposes, as described in its Pages data-collection notice and privacy statement.

Questions and changes

For questions about the app or its data handling, use the support email shown on the Google consent screen. Do not post backup data or credentials to a public GitHub issue. Changes to these practices will be reflected on this page.
